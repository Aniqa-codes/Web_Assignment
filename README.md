 Café Website

This is a responsive café website developed using HTML5, CSS3, and JavaScript. It provides information about the café, displays its menu and offers an interactive user experience through navigation, forms, and other website features.

 Features

- Responsive website layout
- Navigation menu
- Café information and menu section
- Images and content cards
- Interactive feedback/contact form
- JavaScript form validation
- Light and Dark mode functionality

 Technologies Used

- HTML5
- CSS3
- JavaScript

 How to Run the Project

You can view the live project directly here:

[Live Demo](https://aniqa-codes.github.io/Web_Assignment/)

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.
